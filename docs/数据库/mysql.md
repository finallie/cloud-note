## Innodb

支持事务、行级锁、外键、mvcc、使用写前日志支持崩溃恢复、聚蔟索引

## Innodb记录结构

### Innodb页

以页作为磁盘和内存之间交互的基本单位，InnoDB中页的大小一般为 16 KB

### InnoDB行格式

额外信息

- NULL值列表 每个可null的列占用一个bit
- 变长字段长度列表 varchar、变长编码的char 占用1-2个字节
- rowid 无自定义主键时作为隐藏主键
- 事务id
- 回滚指针

## B+树

节点又称为页，默认为16KB，可使用mmap进行io读写
k叉树，树高度一般不超过4
叶节点保存所有行数据，非叶节点保存索引数据，节点内数据按索引顺序存储，可使用二分查找
同层节点按索引顺序双向链接 方便范围查询

## 索引

### innodb索引类型

- B+树 默认索引
- 倒排索引 用于全文索引
- r-树 用于GIS数据类型

### 聚蔟索引

主键+行数据

### 二级索引

非主键索引列+主键 需要回表（回表通常是随机io，需要回表的记录越多，使用二级索引的性能就越低，此时可能不如全表扫描。可以添加limit限制，使优化器倾向于选择二级索引+回表）

### 联合索引

多个列的索引，索引列按顺序存储，查询时可以使用前缀匹配

### 覆盖索引

二级索引列包含查询所需的所有列，避免回表查询

### 唯一索引

自动为unique约束创建索引

## 如何挑选索引

- 只为用于搜索、排序或分组的列创建索引
- 考虑列的基数 最好为那些列的基数大的列建立索引，为基数太小列的建立索引效果可能不好
- 索引列的类型尽量小
- 字符串类型的索引尽量使用前缀索引 使用了前缀将不支持索引排序
- 尽量使用联合覆盖索引

## 单表查询方式

- const 唯一索引等值（非null）查询
- ref 非唯一索引等值查询 或 null查询
- ref_or_null 非唯一索引等值查询或null查询
- range 范围查询
- index 全索引扫描
- all 全表扫描
- eq_ref 被驱动表使用主键值或者唯一二级索引列的值进行等值查找

## 索引合并

使用到多个索引索引合并是数据库在没有复合索引时的“灵活补救方案”，通过多索引并行扫描+结果合并提升查询效率。但因其额外开销，高频查询仍建议用复合索引优化

索引合并更适合：

- 无法预见的查询条件组合
- 索引列更新频繁导致复合索引维护成本高

## 内连接 外连接

内连接（INNER JOIN） 和 外连接（OUTER JOIN） 的本质区别在于 如何处理不匹配的数据行

- 内连接只返回两个表中匹配的行
- 外连接返回匹配的行以及不匹配的行（NULL填充）
- 内连接中ON子句和WHERE子句是等价的
- 外连接中ON子句用于指定连接条件，而WHERE子句用于过滤结果集
- 内连接来说，驱动表和被驱动表是可以互换的

## 连接原理

连接条件有索引使用嵌套循环连接

1. 选取驱动表，使用与驱动表相关的过滤条件，选取代价最低的单表访问方法来执行对驱动表的单表查询
2. 对上一步骤中查询驱动表得到的结果集中每一条记录，都分别到被驱动表中查找匹配的记录

连接条件没有使用索引 被驱动表使用全表扫描 使用join buffer来减少io次数

1. 基于块的嵌套连接（Block Nested-Loop Join）
2. hash join （mysql8+）

## 单表查询执行计划的生成

根据查询条件找出可能利用的索引，生成不同的执行计划，选择代价最低的执行计划
根据表的统计信息（行数、页数、索引列的基数）和成本常数（回表一次的成本、读取页的io成本、单条记录条件判断cpu成本）可以定量的估算出执行计划的代价

## 连接查询成本分析

连接查询总成本 = 单次访问驱动表的成本 + 驱动表扇出数 x 单次访问被驱动表的成本

外连接的驱动表是固定的 内连接需要比较使用不同连接顺序下成本

## mvcc

READ COMMITTD、REPEATABLE READ这两个隔离级别的一个很大不同就是：生成ReadView的时机不同，READ COMMITTD在每一次进行普通SELECT操作前都会生成一个ReadView，而REPEATABLE READ只在第一次进行普通SELECT操作前生成一个ReadView，之后的查询操作都重复使用这个ReadView就好了

二级索引页记录了修改该页的最大事务id，可以避免覆盖索引的回表

## 锁

- 全局锁（通常用于数据备份，使整个数据库只读）
- 表级锁
  - 共享锁、排他锁
  - 意向锁（获取行锁时会加表级意向锁，是表锁与行锁的交互方式）
  - 元数据锁（改变表结构时施加）
  - 自增锁（插入时施加，防止id冲突）
- 行级锁
  - 记录锁（共享锁、互斥锁）
  - 间隙锁（防止幻读）
  - 临键锁（记录锁+间隙锁，防止幻读，默认）
  - 插入意向锁（插入阻塞时）
  - 隐式锁（惰性加锁）
