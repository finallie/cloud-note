## OLTP（事务） vs OLAP（分析）

|| OLTP              | OLAP          |
| ---------- | ----------------- | ------------- |
| 数据量     | 小                | 大            |
| 数据结构   | 结构化            | 非结构化      |
| 数据更新   | 频繁              | 不频繁        |
| 数据查询   | 简单              | 复杂          |
| 数据一致性 | 强                | 弱            |
| 数据处理   | 事务              | 批处理        |
| 数据存储   | 行存储            | 列存储        |
| 数据分析   | 实时分析          | 离线分析      |
| 数据应用   | 事务处理          | 数据挖掘      |
| 数据示例   | 银行交易          | 数据仓库      |
| 数据工具   | MySQL、PostgreSQL | Hadoop、Spark |

## LSM vs B+树

lsm适合于：

- 写多读少 接受稍高的读取延迟
- 数据量大

b+树适合于：

- 读多写少
- 数据量小
- 高并发低延迟的查询要求
- 强一致性事务
