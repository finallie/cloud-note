# jvm

## 内存分布

- 程序计数器
- 栈 分虚拟机栈和本地方法栈，默认大小1-2M
- 堆 默认最大值为物理内存的1/4，存放对象，受垃圾回收器管理
- 方法区 存放类信息、jit编译后代码
- 直接内存 directBuffer（使用directBuffer可以少一次内存拷贝，原因是gc时会移动对象）

## oom异常

- 无法创建新线程（可减少堆内存，缩小栈，修改线程池参数）
- 方法区、直接内存溢出（物理内存不足）
- 堆内存溢出（内存泄漏，内存溢出）

## 内存泄漏

- 静态集合类（HashMap、ArrayList等）
- 缓存无淘汰策略
- threadLocal未清理
- 资源未及时关闭

## 垃圾回收器

- Serial单线程，适合单线程环境
- 并行垃圾回收 适合吞吐率优先、处理器资源稀缺的情况 延迟与内存相关，内存越大延迟越高
- cms jdk9开始弃用移除
- g1 jdk9开始默认，默认最大延迟200ms,平衡吞吐量与延迟
- zgc 低延迟垃圾回收器，暂停时间小于10ms，适合大内存应用

## 工具

- jstat 监控jvm内存使用情况
- jmap 查看堆内存使用情况，生成堆转储文件
- jhat 分析堆转储文件
- jstack 查看线程堆栈信息
- jps 查看jvm进程信息
